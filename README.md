# PETBOT

Облачный мозг и веб-панель управления для домашнего робота PETBOT на базе LILYGO T3 / ESP32.

## План проекта

- **Веб-панель** — состояние робота, настроение, последние события и команды.
- **API** — базовые эндпоинты для проверки сервиса и дальнейшего обмена с ESP32.
- **Прошивка** — отдельная папка firmware для Wi-Fi, OLED-лица, датчиков и безопасного управления моторами.
- **Облачный интеллект** — подключим через серверный API после настройки секретов; ключи нельзя хранить в браузере или прошивке.

## Первый запуск

Проект рассчитан на Vercel. После импорта репозитория откройте корень проекта и оставьте автоматические настройки сборки. Страница панели находится в `index.html`, проверка API — в `api/health.js`.

## Безопасность

На первом этапе API не управляет моторами и не принимает произвольные команды движения. Любое управление двигателями будет добавлено только с ограничениями, тайм-аутом и аварийной остановкой.
